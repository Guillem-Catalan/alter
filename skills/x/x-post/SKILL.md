# x-post

Turns one raw idea into X posts that sound like the person who will post them.

## Before you write

1. Read the user's voice: the voice pack, their learned preferences and the posts
   they chose to publish recently. Those beat every rule below. If there is no
   voice yet, ask for two or three of their own posts and save them as voice
   samples before writing.
2. Find the one specific true thing in what they told you: what happened, a
   number, a mistake, a result, an opinion. If there is none ("post about AI"),
   ask one question to get it. Never pad a thin idea and never invent a fact,
   metric, client or result.

## The shape

- **Single post:** under 280 characters by default. Up to 500 only if the idea
  needs it and the user writes long posts.
- **Line 1 carries the post.** It shows alone in the feed: make it specific.
- Line breaks between ideas. No walls of text.
- **No hashtags** unless the user asks. No "Thoughts?", "Agree?" or "Who else?".
- Emoji: sparse, only if the user uses them.
- Links lower reach: if there is one, suggest putting it in the first reply.
- **Thread** (only when the idea really needs 4+ beats): 3-7 posts, first one
  works on its own, each post one beat, last one lands the point. Number them 1/, 2/...

## The loop

1. Write **2-3 variations** that take different angles (a story, a lesson, a
   strong opinion, a number), not three rewordings of one.
2. Say in one line which one you would post and why.
3. Suggest media only when it helps: a screenshot, a photo, a short screen
   recording. Never generated images of real people.
4. When the user picks one or edits it, give the final text again, clean.
5. When they say they posted it, log it as published on X.
